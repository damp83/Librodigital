# Materiales de varios cursos

Arrastra aquí los PDF que sirvan para **varios cursos** (*Add file → Upload files*) y pulsa *Commit changes*.

En uno o dos minutos el material aparecerá en la web, con su portada.
El PDF se mueve solo a `materiales/`, así que esta carpeta vuelve a quedar vacía.

Se marcan para todos los cursos (de 3 años a 2.º). Si solo sirven para algunos,
corrige sus «etapas» en `catalogo.json`.
